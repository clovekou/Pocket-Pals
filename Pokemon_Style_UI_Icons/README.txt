# Pokémon-inspired Pixel UI Icon Pack

A starter set of pixel-art UI assets based on the two game screenshots.

## Contents
- `01_Navigation/` — Bag, Care, Explore, Party, and Dex icons.
- `02_Items/` — Oran Berry, Rare Candy, Pearl, Star Piece, Nugget, and extra item icons.
- `03_Shop_and_Rewards/` — Shop, currency, gifts, rewards, cart, and treasure icons.
- `04_Settings_and_Status/` — Settings, device, toggles, sound, phone, battery, Wi-Fi, and utility icons.
- `05_Buttons_and_Controls/` — Use, Select, Cancel, Back, Close, Info, plus/minus, confirm, and Poké Ball controls.
- `Source_Sheets/` — Original generated sheets for reference.

## Image details
- Individual icons are PNG files with transparent backgrounds.
- Each individual icon is centered on a 128 × 128 canvas.
- Pixel-art edges are kept crisp (nearest-neighbor scaling).
- Some button assets intentionally include their button face and label; use the standalone icons for replacing individual pictograms.

## Integration
Use the PNGs as image assets in your game. If your UI uses a different display size, scale them with nearest-neighbor / pixelated rendering to preserve the pixel-art look.

This is a first matching pass from the screenshots. If you send the rest of your game's icon screenshots, I can make a second pack that matches the remaining icons and naming conventions more closely.
