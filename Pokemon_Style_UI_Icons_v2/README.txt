# Pokémon-style UI icons, v2 (redrawn)

The same 65 icons as Pokemon_Style_UI_Icons/, with the same folders and file names,
redrawn as clean 32x32 pixel art and scaled 4x to 128 x 128 transparent PNGs.

- Every icon uses the same 1px navy outline, a light top-left rim and a darker bottom-right rim.
- Round items (balls, berries, coins, the pearl) get a soft lower-right shadow for depth.
- Nothing is cropped and there are no leftover pieces from a sprite sheet; each icon is centred.

Compare/ holds side-by-side sheets: original on the left, v2 on the right.

To change or add an icon, edit tools/make_ui_icons.py and run:
    python3 tools/make_ui_icons.py
